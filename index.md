## 💡 What dropzone Does

dropzone watches the folders you choose and helps you organize files with rules. A rule is a simple instruction. For example, you can create a rule that moves screenshots to a Screenshots folder, moves installers to an Installers folder, or groups documents by file type. You choose the rule, and dropzone shows you what will happen before it happens.

The app is useful when your Downloads folder becomes a long list of files with names you do not recognize. Instead of sorting everything by hand, you can build a rule once and reuse it. You can also preview the changes so you know where each file will go. If something looks wrong, you can cancel or undo the action.
